# Hlektrismos.gr — ATLAS CRM

The Hlektrismos.gr public website and ATLAS CRM application.

The root route (`/`) serves the public Hlektrismos.gr landing page and customer-facing information pages. The hash route `#/dashboard` serves the authenticated ATLAS CRM for Admin / Back Office and Sales Agent users.

Built with React, Vite, TypeScript and Supabase. Deployed on Vercel.
