# Οδηγός ATLAS: έγγραφα εκμάθησης

Αυτός ο φάκελος είναι η **πηγή** του «Οδηγού ATLAS» μέσα στο CRM. Κάθε αρχείο `.md` (εκτός από αυτό και όσα αρχίζουν με `_`) είναι ένας οδηγός, που ενσωματώνεται στην εφαρμογή κατά το build. Δεν υπάρχει ξεχωριστή βάση για την τεκμηρίωση: ό,τι γράφεται εδώ και περνά τους ελέγχους, εμφανίζεται στο CRM.

## Μορφή ενός οδηγού

Το όνομα του αρχείου είναι το `id` + `.md`. Στην αρχή υπάρχει front matter με **όλα** τα παρακάτω:

| Κλειδί | Τι είναι |
| --- | --- |
| `id` | Σταθερό αναγνωριστικό (λατινικοί χαρακτήρες, αριθμοί, `-`). Δεν αλλάζει ποτέ. |
| `title` | Τίτλος. |
| `category` | Κατηγορία (ομαδοποίηση στον οδηγό). |
| `roles` | `[admin, sales_agent]`: ποιοι λογαριασμοί βλέπουν τον οδηγό. Μόνο αυτοί οι δύο. |
| `level` | `beginner`, `intermediate` ή `advanced`. |
| `status` | `verified`, `partially-verified` ή `planned` (δείτε παρακάτω). |
| `updated` | Ημερομηνία τελευταίας αναθεώρησης, `YYYY-MM-DD`. |
| `version` | Έκδοση του οδηγού. Όταν η εφαρμογή αλλάξει, αυξάνεται και ο οδηγός εμφανίζεται ως «ίσως παλιός» μέχρι να αναθεωρηθεί. |
| `area` | Η περιοχή της εφαρμογής που τον αφορά. |
| `route` | Η σελίδα της εφαρμογής (PageKey) ή `none`. |
| `related`, `keywords`, `summary` | Σχετικοί οδηγοί, λέξεις-κλειδιά για την αναζήτηση, σύντομη περίληψη. |

## Κατάσταση επαλήθευσης

- **verified**: κάθε ισχυρισμός προέρχεται από τον κώδικα ή από παρατηρημένη συμπεριφορά της εφαρμογής.
- **partially-verified**: ο οδηγός περιγράφει όσα φαίνονται στον κώδικα, αλλά κάποιο μέρος εξαρτάται από ρυθμίσεις ή από λειτουργίες που δεν ελέγχθηκαν σε πραγματικό περιβάλλον.
- **planned**: η λειτουργία δεν υπάρχει ακόμη. Ο οδηγός το λέει καθαρά και δεν περιέχει οδηγίες χρήσης.

## Κανόνες γραφής

1. **Μόνο ό,τι υπάρχει.** Μην περιγράφετε λειτουργία, δικαίωμα ή ροή που δεν υπάρχει. Αν δεν είστε σίγουροι, γράψτε `partially-verified` και πείτε τι δεν ελέγχθηκε.
2. **Ονόματα της οθόνης σε «εισαγωγικά».** Ό,τι είναι μέσα σε `«…»` πρέπει να υπάρχει αυτούσιο στον κώδικα της εφαρμογής. Ένα τεστ το ελέγχει και αποτυγχάνει αν δεν βρεθεί.
3. **Δύο ρόλοι.** Admin / Back Office (κοινός λογαριασμός) και Sales Agent. Δεν υπάρχει Manager.
4. **Πίνακες από τον κώδικα.** Δικαιώματα, σελίδες και στάδια δεν γράφονται με το χέρι. Χρησιμοποιήστε `@embed roles`, `@embed pages`, `@embed stages`.
5. **Χωρίς προσωπικά δεδομένα.** Φανταστικά στοιχεία μόνο (π.χ. `dokimi@example.invalid`, `210 000 0000`). Ποτέ κωδικοί, κλειδιά ή πραγματικοί πελάτες.
6. **Προς τον αναγνώστη.** Απλή ελληνική γλώσσα, βήματα που γίνονται, χωρίς τεχνικούς όρους όπου δεν χρειάζονται.

## Πώς ελέγχεται

`npm test` τρέχει το `src/lib/__tests__/learning-centre.test.mjs`: αναλύει κάθε οδηγό, ελέγχει τα υποχρεωτικά πεδία και τις ενότητες, ότι κάθε σύνδεσμος οδηγεί σε υπαρκτό οδηγό, ότι κάθε «όνομα οθόνης» υπάρχει στον κώδικα και ότι δεν υπάρχουν διευθύνσεις email, τηλέφωνα ή κλειδιά.
