## Όροι

| Όρος | Τι σημαίνει |
| --- | --- |
| Lead | Μια πρώτη επαφή που δεν έχει γίνει ακόμη πελάτης. |
| Πελάτης | Δημιουργείται όταν ένα lead μετατρέπεται σε case. |
| Case | Ο φάκελος μιας πώλησης, που περνά από στάδια. |
| Στάδιο | Το σημείο της πορείας του case, από το Νέο ως την Ενεργοποίηση. |
| Πάροχος | Η εταιρεία ενέργειας στην οποία καταχωρίζεται η αίτηση. |
| Πρόγραμμα | Το πακέτο ή τιμολόγιο ενός παρόχου. |
| Follow-up | Υπενθύμιση για επόμενη επαφή. |
| Παράδοση | Η μεταφορά μιας συμφωνημένης πώλησης από τον Sales Agent στο Back Office. |
| Back Office | Η ομάδα που ελέγχει και διεκπεραιώνει τους φακέλους. |
| Check In / Check Out | Δήλωση άφιξης και αποχώρησης σε επίσκεψη. |
| Διεκπεραίωση | Η ουρά των cases που περιμένουν δουλειά από το Back Office. |
| Εξαίρεση | Ένδειξη του Back Office σε case που κόλλησε, π.χ. η προσφορά δεν έγινε δεκτή, ο πελάτης δεν απαντά, λείπει η υπογραφή ή ο πάροχος απέρριψε την αίτηση. |
| Ενεργοποίηση | Το στάδιο όπου ο πάροχος ενεργοποιεί τη νέα σύμβαση. |
| Ορατότητα πωλητών | Η ρύθμιση που ορίζει τι βλέπει κάθε Sales Agent. |
| Κάδος | Ο χώρος των διαγραμμένων στοιχείων, από όπου μπορούν να επανέλθουν. |
