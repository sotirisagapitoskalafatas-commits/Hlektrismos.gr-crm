# Production rollout report

The live rollout report (evidence by environment, blockers and risks, owner actions, the approval checkpoint) contains production-specific findings and personal data, so it is **kept privately by the owner** and is not published in this public repository.

What is public: the procedure (`PRODUCTION_ROLLOUT_CHECKLIST.md`), the tooling (`scripts/ops/*`, `scripts/qa/*`), the review package (`docs/security/INDEPENDENT_REVIEW_PACKAGE.md`) and the Auth configuration steps (`AUTH_URL_CONFIGURATION.md`).
